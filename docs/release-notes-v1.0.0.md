首个正式版本。

## 下载哪个？

两个版本**功能完全一样**，都**自带 .NET 运行库**，不需要另外安装任何东西：

| 版本 | 文件 | 说明 |
| --- | --- | --- |
| **安装版** | `GameVault-1.0.0-Setup.exe` | 带简体中文安装向导，可创建开始菜单 / 桌面快捷方式，自带卸载程序。默认「仅为我安装」，不需要管理员权限 |
| **便携版** | `GameVault-1.0.0-Portable.zip` | 解压即用，不写注册表、不装任何东西。整个文件夹拷走就是迁移 |

**系统要求**：Windows 10 / 11 64 位。

## 这个版本有什么

- **扫描 Steam 库**批量导入已安装的游戏，含 D 盘、F 盘等第二库；也可手动添加任意程序
- **自动获取简介和封面**：Steam 上的游戏走 Steam 公开接口；Steam 没收录的自动改用 VNDB、萌娘百科、SteamGridDB
- **简介自动中文化**：抓到英文或日文简介时，先换名字再找一遍中文，仍然找不到才调用机器翻译
- **一键启动** + 精确到秒的**游玩时长统计**
- **分类整理**：自定义分类、收藏、最近游玩，四种排序、网格 / 列表两种视图
- **自定义背景壁纸**：支持 PNG / JPG / BMP / WEBP / GIF 图片，以及 **MP4 动态壁纸**（循环播放，要求分辨率 ≥ 1280×720）
- **窗口大小自由调整**并记住，内置 720p / 1080p / 2K / 带鱼屏 / 4K 预设
- **系统托盘后台运行**：点 ✕ 时可选「每次询问 / 最小化到后台 / 直接退出」，收进托盘后已启动的游戏继续计时
- **开机自动启动**（可选），不需要管理员权限
- **无边框界面**，所有控件自绘；数据目录自适应便携 / 安装两种模式

## 数据存在哪里

- 便携版：程序旁边的 `data\` 文件夹
- 安装版：安装到 `Program Files` 时程序目录只读，数据会自动改放到 `%APPDATA%\一切游戏管理家\data`

程序里的「关于」窗口会显示当前是哪种模式以及数据的完整路径。
